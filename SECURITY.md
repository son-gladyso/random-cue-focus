# Security policy

## Supported versions

Only the latest development version is currently supported; no production release has been declared.

## Reporting

Please report vulnerabilities privately through GitHub's security-advisory workflow for this repository. Do not include sensitive goal text or session records in a public issue. Include the affected commit/version, platform, reproduction steps, impact, and the minimum sanitized evidence needed to reproduce.

## Scope

Relevant issues include unintended data disclosure, notification text exposed contrary to settings, unsafe file paths or permissions, data corruption during migration, native-channel misuse, and dependency vulnerabilities.
